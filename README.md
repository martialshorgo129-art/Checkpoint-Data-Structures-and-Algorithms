## 2. Data Structures

Data structures are ways of organizing and storing data so that it can be accessed and modified efficiently.

During this checkpoint, I explored the following structures:

### 2.1 Array

An Array stores multiple elements in an ordered collection. Each element can be accessed using its index.

**What I understood:**
- Elements are organized in positions called indexes.
- Indexing generally starts at 0.
- Elements can be accessed directly using their indexes.

**What I practiced:**

Understanding how to identify the position of an element inside an array and how indexing works.

### 2.2 Linked List

A Linked List is a collection of nodes connected through references or pointers.

**What I understood:**
- Each node contains data and a reference to another node.
- Elements are connected sequentially.
- Traversal starts from the first node.

**What I practiced:**

Following nodes from the beginning of a linked list to locate a specific value.

### 2.3 Stack

A Stack follows the LIFO principle (Last In, First Out).

**What I understood:**
- The last element added is the first one removed.
- Push adds an element.
- Pop removes the top element.

**Real-world example:** A stack of plates.

### 2.4 Queue

A Queue follows the FIFO principle (First In, First Out).

**What I understood:**
- The first element added is the first one removed.
- Enqueue adds an element.
- Dequeue removes an element from the front.

**Real-world example:** People waiting in a queue.

### 2.5 Hash Table

A Hash Table stores information using key-value pairs.

**What I understood:**
- Each value is associated with a key.
- A hash function helps determine where data is stored.
- It allows efficient data retrieval in typical cases.

### 2.6 Binary Search Tree (BST)

A Binary Search Tree is a tree structure used to organize data.

**What I understood:**
- Smaller values are placed on the left.
- Larger values are placed on the right.
- Searching can be efficient when the tree is balanced.

### 2.7 Heap

A Heap is a tree-based data structure used to manage priorities.

**What I understood:**
- A Max Heap keeps the largest value at the root.
- A Min Heap keeps the smallest value at the root.
- It is commonly used in priority queues.

### 2.8 Graph

A Graph represents relationships between different elements.

**What I understood:**
- Vertices represent elements or nodes.
- Edges represent connections between vertices.
- Graphs can be directed or undirected.

## 3. Sorting Algorithms

Sorting algorithms are techniques used to arrange data in a specific order, usually ascending or descending.

### 3.1 Bubble Sort

Bubble Sort compares neighboring elements and swaps them when they are in the wrong order.

**Key concept:** Repeated comparison and swapping of adjacent elements.

### 3.2 Selection Sort

Selection Sort repeatedly finds the smallest element and places it in its correct position.

**Key concept:** Finding the minimum value during each iteration.

### 3.3 Insertion Sort

Insertion Sort builds a sorted portion of the array by inserting each new element into its appropriate position.

**Key concept:** Inserting elements into the correct position.

### 3.4 Merge Sort

Merge Sort uses the divide-and-conquer technique.

**Key concept:**
1. Divide the array into smaller parts.
2. Sort each part.
3. Merge the sorted parts.

### 3.5 Quick Sort

Quick Sort also uses the divide-and-conquer approach.

**Key concept:**
1. Select a pivot.
2. Partition the elements around the pivot.
3. Recursively sort the resulting partitions.

### 3.6 Counting Sort

Counting Sort organizes elements by counting how many times each value appears.

**Key concept:** Using frequency counts instead of directly comparing elements.
